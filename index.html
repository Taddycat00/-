如何串接您的 Neon 或雲端 PostgreSQL？

本系統後端使用標準 Node.js pg 連線池，支援 **Neon、Supabase、Google Cloud SQL、AWS RDS** 等所有標準 PostgreSQL 資料庫。

# 在專案環境變數設定 DATABASE_URL 即可自動連線並建置資料表：
DATABASE_URL="postgresql://username:password@ep-example.neon.tech/neondb?sslmode=require"
  • 若尚未設定 DATABASE_URL，系統會自動切換為本機離線模式 (LocalStorage)，所有功能依然順暢可用。
  • 當設定完成並連線時，系統會自動在 PostgreSQL 建立 customers、vendors、products 與 quotes 資料表，並支援雙向自動同步。
